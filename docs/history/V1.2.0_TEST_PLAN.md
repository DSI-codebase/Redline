# DSI Redline v1.2.0 — Feature Test Plan

Hands-on checks for the **v1.2.0** additions: movable tabs, copy/paste, format
painter, sticky styles, stacking order, smoother "Draw new", commenter rename,
**view-only mode** for un-sidecar-able files, **Print** (+ preview), the
**sheet-number split** on rotated/scanned sets, and **sharper zoom past 400%**.
Tick each box; note `❌ <detail>` on any failure.

> [!note] Prepare
> - [ ] A normal **vector** PDF (real text layer) to mark up.
> - [ ] A **rotated** drawing set (a landscape AutoCAD plot) and, if you have one,
>       a **scanned** (image-only) set — for the sheet-split checks.
> - [ ] A way to make a **very-long-named** copy for the view-only test
>       (recipe in section **H**).
> - [ ] A printer — a real one, or "Microsoft Print to PDF" / "Save as PDF".

---

## A. Movable / floatable tabs

- [ ] Drag the **TODO** tab's title bar out of the window → it becomes its **own
      standalone window**. Move it to a second monitor if you have one.
- [ ] Drag it back onto the tab strip → it **re-tabs** with the others.
- [ ] Drag a tab to the **left/right edge** → it docks side-by-side (split view).
- [ ] Close a pane with its **✕**, then reopen it from **View ▸ Panes ▸ <name>**.
- [ ] **View ▸ Reset panel layout** → all five panes snap back to one tab group,
      Viewer in front, Navigation left / Comments right.
- [ ] Close and reopen the app → your last tab/dock arrangement is **remembered**.

## B. Copy & paste marks

- [ ] Draw a **rectangle**. Right-click it ▸ **Copy** (or `Ctrl+C`).
- [ ] Right-click empty canvas ▸ **Paste 1 mark here** → a copy lands at the click.
- [ ] Press `Ctrl+V` a few times → copies **cascade** (offset), don't stack exactly.
- [ ] **Rubber-band select** a rectangle + an arrow + a cloud, `Ctrl+C`, `Ctrl+V`
      → all paste together and land **selected**.
- [ ] `Ctrl+Z` once → the whole paste undoes in **one step**.
- [ ] With **no mark selected**, `Ctrl+C` still copies selected **text** (old behaviour).

## C. Format painter

- [ ] Give a rectangle a distinct **colour + fill + opacity + border width**.
- [ ] Right-click it ▸ **Copy formatting**.
- [ ] Right-click a **second rectangle** ▸ **Paste formatting** → it takes the
      colour/fill/opacity/width but **keeps its own position** (and any text).
- [ ] Right-click a mark of a **different type** (e.g. an arrow) → **Paste
      formatting** is **greyed / absent** (same-type only).

## D. Sticky styles

- [ ] Draw a **text box**, set colour = red, font = 18, a fill → save it.
- [ ] Start **another** text box → it **defaults** to red / 18 / that fill
      (you don't re-declare them). The **text** is **not** carried over.

## E. Stacking order

- [ ] Overlap three filled rectangles so you can see who's on top.
- [ ] Right-click the bottom one ▸ **Order ▸ Bring to Front** → it moves on top.
- [ ] **Send to Back**, **Bring Forward**, **Send Backward** each move it one/all
      the way as labelled. `Ctrl+Z` reverses each.
- [ ] **Save**, reopen the file → the stacking order is **preserved**.
- [ ] Export the annotated PDF, open it in Chrome/Adobe → order matches.

## F. Smoother "Draw new"

- [ ] With a drawing tool, start a mark **on top of an existing one** → the
      **Edit / Draw new / Cancel** prompt appears.
- [ ] Choose **Draw new** → you can **finish drawing** the new object with **no
      second pop-up** interrupting the placement.

## G. Rename a commenter

- [ ] In the **Comments** sidebar, **double-click a name** in the **By** column →
      confirm → type a new name → the mark's author updates.
- [ ] Do the same on the **TODO** tab's **Commenter** column.
- [ ] For a name shared by several marks (e.g. imported `AutoCAD`), choose
      **rename all** → every mark by that name updates in **one undoable step**
      (`Ctrl+Z` restores them all).

## H. View-only mode (un-sidecar-able filename)

> Make a long-named copy first. **Windows PowerShell**, in the file's folder:
> ```powershell
> Copy-Item drawing.pdf ("x" * 240 + ".pdf")
> ```
> (a ~240-char name makes the `.markup.db` sidecar name too long to create.)

- [ ] Open that long-named PDF → it **opens for viewing** (no "Open failed"),
      and a **popup** explains markup is off and how to fix it (rename shorter).
- [ ] **Greyed out:** the drawing tools + Fill/Color/Pen/Font controls, and
      **Save**, **Save As**, **Export annotated/flattened**.
- [ ] **Still works:** scroll/zoom, **Find** (`Ctrl+F`), page navigation,
      **Print**, and the **PDF Tools** tab.
- [ ] Rename the file to something short and reopen → markup + saving are **back**.

## I. Print (`Ctrl+P`) & Print preview

- [ ] Add a couple of marks, then **File ▸ Print…** (or `Ctrl+P`) → the **system
      print dialog** appears **directly** (no "contacting printer" hang, no forced
      preview window).
- [ ] Print to **PDF / "Print to PDF"** → the output shows the pages **with the
      marks**, fitted and centred.
- [ ] Set a **page range** (e.g. 2–3) → only those pages print.
- [ ] **File ▸ Print preview…** → the pages render in a preview; the toolbar has an
      **Include markups** checkbox that's **on** by default.
- [ ] Uncheck **Include markups** → the preview re-renders the **clean drawing**
      (no marks); printing from there produces a clean copy.
- [ ] Print a **view-only** file (from **H**) → it prints fine (marks aren't
      possible there, but the drawing prints).

## J. Sheet-number split — rotated & scanned (PDF Tools)

- [ ] On a **rotated** searchable set: **PDF Tools ▸ Split by sheet number**, drag
      a box around the sheet number → the **preview shows the number** (not
      "(nothing found)"). Split → files are named `…-sheet<NNN>.pdf`.
- [ ] On a **scanned** set with Tesseract installed: same steps → the box is
      **OCR'd** and the preview shows the number (no Settings switch needed).
- [ ] A box left over blank space still falls back to page-number naming and is
      reported.

## K. Sharper zoom past 400%

- [ ] Zoom a normal sheet **past 400%** (up to ~800%) → the drawing stays **crisp**,
      not a blurry upscale.
- [ ] A very large (E-size) sheet still zooms without the app running out of memory.

---

## L. Quick regression (areas these touched)

- [ ] Open a normal PDF, draw one of **each** mark type, add a **note**, flag a
      **TODO**, **Save**, reopen → everything round-trips.
- [ ] **Undo/redo** across a draw, a paste, an order change and a rename.
- [ ] **Rotate** the view (`↺ / ↻`) → marks rotate with the page.
- [ ] **Wire / Component** extraction still runs and exports.
- [ ] Export annotated **and** flattened PDFs open correctly in Chrome/Adobe.
